## Hosting
GitHub Pages can't be switched on from Actions or the API connector for a new repo. Until Pages is enabled here (Settings -> Pages -> Deploy from branch `main`, `/ (root)`), the same files are served from the `software-guides/` folder of `jhodges3401-code/jhodges3401-code.github.io`. After you enable Pages here, delete that folder so there's only one copy.
